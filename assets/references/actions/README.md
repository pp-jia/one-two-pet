## 推荐优先级

1. 荡秋千（动态最大，最像大肥鱼的玩耍动作）
2. 喝牛奶（吃喝互动，有明确道具）
3. 比耶吐舌（表情最强，适合点击/成功）
4. 脑阔疼（情绪最强，适合出错/思考卡住）

## 使用方式

- **动作/道具参考**：`01-swing.png`、`03-milk.png` 可以直接给豆包当动作参考；角色外观仍以 `yier-hd` 的 canonical 首帧为准。
- **表情/手势参考**：`04-peace.png`、`06-headache.png` 是半身图，不要直接当首帧；先补全全身、换绿幕，再图生视频。
- 所有参考图里的文字、UI 按钮、白底/粉底都要去掉，最终首帧必须是 16:9 纯绿幕、全身、脚底同线。
