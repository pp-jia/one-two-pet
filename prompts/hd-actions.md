# 一二 HD 动作提示词（豆包 / 图生视频）

> 用途：把「一二」从 192×208 像素图集升级成接近大肥鱼质感的 640×360 透明动画。
> 目标不是一次做 35 段，而是先做 5 个高动态动作，把“展示效果”拉起来。

## 0. 参考图准备

### 0.1 标准角色图（canonical）

用你那段 720p 绿幕视频的 **0 秒正面站立帧**（无水印、全身、脚底同线）作为标准参考。
后面每个动作都上传同一张，保证一二不会“每段长得不一样”。

如果重新生成，提示词：

```text
16:9 横屏，纯绿幕背景 #00FF00，全身，正面站立，角色居中，
脚底在画面高度 85% 处，头顶留 15% 空间，双手自然下垂，表情中性。
只出现一个角色：一二，白色圆润 Q 版身体，深棕色圆耳朵，粉色腮红，
黑色小圆眼，tiny w 形嘴，没有眉毛，脖子上有深棕色小领结，
头身比约 1:1，短手短脚，软萌温柔。
高清动画设定图，干净线条，柔和配色，不要像素风、不要马赛克、
不要阴影、不要地面、不要文字、不要水印。
```

## 1. 我选的 5 个动作

| 优先级 | 动作 | 分类 | 为什么选 |
| ---: | --- | --- | --- |
| 1 | 吃辣条 | 吃什么 | 有明确道具、咬/辣到/碎屑，动态最强，最像大肥鱼的吃播动作 |
| 2 | 荡秋千 | 玩耍 | 秋千+前后荡+踢腿，构图完整，和大肥鱼荡秋千同类 |
| 3 | 背后抱抱 | 双人互动 | 布布从背后抱住一二，有爱心和贴贴，情绪价值最高 |
| 4 | 拜托 球球你 | 点击/请求 | 双手合十+歪头+闪光，表情最强，适合点击回应 |
| 5 | 脑阔疼 | 工作出错 | 抱头+闭眼+摇晃，梗感强，适合工作状态/出错 |

备选：喝牛奶（吃喝）、比耶吐舌（成功/点击）。

## 2. 通用参数

| 项目 | 建议 |
| --- | --- |
| 模式 | 图生视频 / 首帧（支持多图就加动作参考） |
| 时长 | 5 秒；支持 6/10 秒再拉长 |
| 分辨率 | 1080p（720p 也够 640×360） |
| 帧率 | 24fps |
| 镜头 | 固定机位，不要推拉/旋转/缩放 |
| 水印 | 能关就关；不能关就保持在角落，后期裁掉 |
| 生成数量 | 每个动作 2～4 条，挑角色没变形、绿边干净、没出画的 |
| 首尾帧 | 有“首尾帧”就首尾传同一张；没有就要求结尾回到第一帧姿势 |

## 3. 完整提示词

### 3.1 吃辣条（首选）

```text
以参考图中的「一二吃辣条」为动作和道具参考，只参考拿辣条、咬、被辣到的动作；
不要参考原图的文字“干辣条不~”、GIF 徽标、网页 UI 或白色背景。
角色外观严格保持标准参考图：白色圆润身体、深棕色圆耳朵、粉色腮红、
黑色小圆眼、tiny w 形嘴、没有眉毛、深棕色小领结、短手短脚。
不要改变角色设计，不要出现第二个角色。

16:9 横屏，固定机位，平视，全身，角色始终位于画面中央，
脚底在同一条水平线上，头顶留 15%。纯绿幕背景 #00FF00，
背景干净均匀，无地面、无阴影、无投影、无文字、无水印、
无镜头运动、无缩放、无转场。角色边缘清晰，绿色不溢出。
24fps，高清，干净线条，柔和配色，动画风格。

动作：0-1s 双手拿着一根长长的橙红色辣条，举在胸前；
1-2s 咬一口，辣条变短；2-3s 咀嚼，腮帮子一鼓一鼓，眼睛满足地眯起；
3-4s 被辣到，轻轻吐出舌头、哈气，少量碎屑飞出；
4-5s 再咬一口，露出满足表情。辣条不要消失、不要变形、不要穿过手；
碎屑少量，不要遮挡脸。

最后 0.5 秒回到与第一帧相近的正面站立姿势，角色始终完整入画。
```

**注意**：辣条是橙红色，不要让它变成绿色；碎屑后期也能加，生成时少量即可。

```text

秋千绳从画面上方进入，坐板在画面下方 85% 以内，头顶留 15%。
纯绿幕背景 #00FF00，无地面、无阴影、无树木、无天空、无文字、无水印、
无镜头运动、无缩放、无转场。秋千绳和坐板改为深棕色/米色，不要绿色。
24fps，高清，干净线条，柔和配色，动画风格。

动作：0-1s 坐在秋千上，双手抓绳，轻轻前后晃；
1-2.5s 向后荡起，双腿向前踢，舌头微微吐出，表情开心；
2.5-4s 向前荡回，身体后仰，耳朵轻微跟随；
4-5s 回到中间，继续轻晃。秋千绳和坐板不要断开、不要穿模，

最后 0.5 秒回到与第一帧相近的姿势，角色和秋千始终完整入画。
```

**注意**：原图秋千绳是绿色的，上绿幕会消失；一定要改成深棕色/米色。

## 5. 生成后检查

- 耳朵、领结、腮红颜色有没有变；
- 眼睛有没有变型、变多、变少；
- 手指有没有粘连、多手多脚；
- 白毛边缘有没有明显绿边；
- 脚底有没有漂移、角色有没有出画；
- 动作是不是你要的（吃辣条要看到咬和碎屑；拜托要看到合十和歪头）；
- 首尾姿势是否接近，方便循环；
- 画面里有没有第二个角色或奇怪道具。
